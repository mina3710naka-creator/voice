# 音声入力アプリ

`Ctrl + Shift` を押しながら話すと音声を認識し、フィラー語（えー、あの、なんか…）を除去してテキストボックスに自動入力するブラウザアプリです。ビルド不要・インストール不要で、ZIPをダウンロードして解凍するだけで使えます。

## 使い方

1. このリポジトリを ZIP でダウンロードします（GitHub の `Code` ボタン → `Download ZIP`）。
2. 好きな場所に解凍します。
3. **Google Chrome** または **Microsoft Edge** で `index.html` を開きます（ダブルクリックでOK）。
4. マイクの使用許可を求められたら「許可」を選びます。
5. `Ctrl` キーと `Shift` キーを同時に押しながら話します。押している間は画面に `🔴 録音中...` と表示されます。
6. キーを離すと音声認識結果が整形され、テキストボックスに自動で貼り付けられます。テキストは直接編集・コピーもできます。

## 誤字・フィラー語の除去について

- デフォルトでは、ルールベースで「えー」「あの」「なんか」などのフィラー語や、どもり（同じ文字の連続）を自動的に除去します（追加設定不要）。
- より高精度な誤字修正・言い回しの自然化を行いたい場合は、画面右上の「⚙️ 設定」から OpenAI の API キーを登録し、「AIで誤字・言い間違いを自動修正する」を有効にしてください。
  - APIキーはブラウザの `localStorage`（この端末内）にのみ保存され、OpenAI 以外には送信されません。
  - APIキーを使うと OpenAI 側の利用料金が発生する場合があります。

## 制限事項（重要）

- 音声認識には Web Speech API を使用しているため、**対応ブラウザは Chrome / Edge のみ**です（Safari / Firefox は非対応）。
- ホットキー（`Ctrl+Shift`）は **このブラウザタブがアクティブなときのみ** 有効です。OS全体で動作するグローバルホットキー（他のアプリ操作中でも効く機能）ではありません。
- `file://` で開いた際にマイクへのアクセスがブロックされる環境では、簡易サーバー経由で開いてください。
  ```bash
  # Python がある場合
  python3 -m http.server 8000
  # その後ブラウザで http://localhost:8000 を開く
  ```
