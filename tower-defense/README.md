# タワーディフェンス

ブラウザだけで遊べる、依存ライブラリなしのシンプルなタワーディフェンスゲームです。

## 遊び方

`index.html` をブラウザで開くだけで起動します（ビルド不要）。

```bash
# 例: ローカルサーバーを立てて開く場合
cd tower-defense
python3 -m http.server 8080
# ブラウザで http://localhost:8080 を開く
```

`index.html` をダブルクリックして直接開いても動作します。

## ルール

- 敵は左端から出現し、道に沿って右端の拠点まで進みます。拠点に到達されるとライフが減ります。
- ライフが0になるとゲームオーバー、全20ウェーブを防衛しきると勝利です。
- 道以外の空きマスにタワーを建設できます。右側パネルからタワーの種類を選び、盤面をクリックして設置します。
- 既存のタワーをクリックすると強化・売却ができます。
- 「ウェーブ開始」ボタンで次のウェーブを呼び出します。倍速表示や一時停止も可能です。

## タワーの種類

| タワー | 特徴 |
| --- | --- |
| 🏹 アロータワー | 安価で連射が速い基本タワー |
| 💣 キャノンタワー | 範囲ダメージで密集した敵に強い |
| 🎯 スナイパータワー | 超長射程・高火力だが連射は遅い |
| ❄️ フロストタワー | 命中した敵を一定時間減速させる |

## 敵の種類

- 通常（緑）: バランス型
- 高速（黄）: HPは低いが素早い
- タンク（茶）: HPが高く足は遅い
- ボス（赤）: 5ウェーブごとに出現する強敵
